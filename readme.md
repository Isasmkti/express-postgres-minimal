# Minimal Express & PostgreSQL API

This is a minimal codebase template for building a RESTful API using Node.js, Express.js, and PostgreSQL (utilizing the `pg` / node-postgres package). It serves as an excellent starting point for projects requiring direct database connections via raw SQL.

## Key Features

- **Express.js** for web server functionality and routing.
- **PostgreSQL** for relational database management.
- **Dotenv** for secure environment variable management.
- **Nodemon** for automatic server restarts during development.
- **Connection Pool** structure for optimized database performance.

## Prerequisites

Before you begin, ensure you have the following installed on your system:
- [Node.js](https://nodejs.org/) (version 14 or higher)
- [PostgreSQL](https://www.postgresql.org/) (ensure the database server is running locally or remotely)
